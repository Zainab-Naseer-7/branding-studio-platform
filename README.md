# BRANDORA — World-Class Branding Studio Platform

> **"Build a Brand People Remember."**

An ultra-premium, production-grade Branding Studio Operating System designed for creative agencies, brand strategists, venture builders, and enterprise marketing leaders. BRANDORA unifies identity architecture, vector asset management, color science, typographic hierarchy, client relationships, and brand consistency analytics into one seamless, blazingly fast workspace.

---

## 💎 Visual Direction & Design System

- **Chromatic Foundation**: Deep Midnight & Obsidian Glass (`#07080A`, `#0C0E14`, `#12151E`, `#171B26`)
- **Signature Accents**: Electric Coral (`#FF5E4D`) & Warm Amber Glow (`#FFA034`)
- **Typography & Scale**: High-contrast Ivory (`#F4F4F6`), editorial tracking, system font stack with zero render-blocking webfont delays.
- **Micro-Interactions**: Hardware-accelerated cubic-bezier transitions, glassmorphism surface blurs (`backdrop-filter: blur(18px)`), interactive SVG charts, and radial consistency score meters.
- **Zero Dead Buttons**: Every button, pill, modal trigger, copy handler, download action, and form is wired to genuine interactive application logic.

---

## 📂 Project Architecture (Root Files Only)

As per the strict system requirements, **no nested folders or directories exist**. All assets, logic, and styles reside directly in the root:

```text
Branding Studio Platform/
├── index.html        # Semantic HTML5 app shell, modals, 20 studio views & inline SVGs
├── style.css         # Complete design system tokens, responsive breakpoints & micro-animations
├── script.js         # Reactive LocalStorage engine, view router, chart generator & controller
└── README.md         # Full platform documentation & developer guide
```

## 🚀 How to Run

1. **Direct Browser Execution**:
   Simply double-click `index.html` or open it in any modern browser (Chrome, Firefox, Safari, Edge).
   *No build step, no npm install, and no external web dependencies required.*

2. **Local Web Server (Optional)**:
   ```bash
   # Python
   python -m http.server 8000

   # Node.js
   npx serve .
   ```
   Navigate to `http://localhost:8000`.
